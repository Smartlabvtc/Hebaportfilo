## Portfolio Content Strategy

The website leads with the strongest story rather than a generic biography: technology becomes meaningful when another person can use it with confidence. The hero introduces this promise, the project cards prove it with audience and reach metrics, the timeline establishes credibility, and the contact section converts interest into a conversation.

The portfolio deliberately avoids invented testimonials because none were included in the supplied materials. A testimonial module can be added later when written endorsements and permission to publish them are available.

## Visual Design System

| Token | Value | Use |
|---|---|---|
| Ink | `#20242B` | Primary text, footer, high-contrast surfaces |
| Paper | `#FBFAF7` | Main background |
| Warm mist | `#F4F1EB` | Alternating section background |
| Lime | `#C8F34A` | Primary accent, status, metric emphasis |
| Violet | `#7C5CFF` | Links, creative-tech accent, CTA surface |
| Orange | `#FF7A59` | Secondary accent for project differentiation |
| Teal | `#B9EEE3` | Optional supporting accent |
| Line | `#E9E4DB` | Borders and separators |
| Body soft | `#5C6471` | Secondary text |

**Typography:** IBM Plex Sans Arabic for Arabic body and UI text; IBM Plex Mono for metadata and technical labels; Playfair Display for the small brand mark only. The system is intentionally editorial and technical: Arabic stays highly readable, while monospace labels signal craft and technology without overwhelming the page.

**Interaction rules:** Hover transitions stay under 250ms. Buttons provide a 3% active-scale response. Cards lift subtly on hover. Non-essential animation is disabled under `prefers-reduced-motion`. All major actions use visible focus rings, semantic landmarks, meaningful link text, and keyboard-reachable controls.
